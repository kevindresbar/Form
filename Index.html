Clases

Selectores

Son la forma en que indico qué elementos de mi página quiero modificar o estilizar. Básicamente sirven para “seleccionar” etiquetas específicas del documento HTML, como párrafos, títulos, clases o identificadores, para aplicarles estilos como colores, tamaños o márgenes. Gracias a los selectores puedo controlar exactamente qué partes de la página cambian sin afectar todo el contenido.

Propiedades

Son las características que puedo cambiar de un elemento en una página hecha con HTML. Básicamente son las que definen cómo se va a ver algo, por ejemplo el color del texto, el tamaño de la letra, el fondo o los márgenes. Cada propiedad tiene un valor que indica cómo quiero que se aplique ese estilo, lo que me permite personalizar la apariencia de los elementos de la página.

Medidas

Las medidas rem, px y % en CSS son unidades que usamos para poner tamaños en una página HTML. px es una medida fija que sirve para poner un tamaño exacto, por ejemplo en texto o imágenes. % es una medida que depende del tamaño del elemento padre, o sea que cambia según el espacio que tenga. rem también es una medida relativa, pero se basa en el tamaño de letra principal de la página. Estas medidas ayudan a que el diseño de la página se vea bien y se adapte mejor a diferentes pantallas.

Flexbox

En CSS también aprendí sobre Flexbox, que sirve para organizar los elementos de una página usando display: flex. Esto permite acomodar cosas como menús o secciones de forma ordenada y que la página se adapte mejor cuando cambia el tamaño de la pantalla, evitando que se deformen los elementos. También aprendí a hacer menús donde las páginas se conectan entre sí usando la etiqueta a en HTML, que sirve para crear enlaces. Además, si quiero que un enlace se abra en una pestaña nueva, puedo usar target="_blank".

Display

En HTML aprendimos a crear formularios usando diferentes tipos de input según lo que se necesite, por ejemplo para escribir texto, correos, contraseñas o seleccionar opciones. También vimos cómo conectar estos elementos y organizarlos mejor usando CSS. Con propiedades como display podemos acomodar los campos del formulario para que queden bien alineados y ordenados en la página.

BoxModel

El Box Model en CSS es la forma en que se estructura cada elemento dentro de una página hecha con HTML. Básicamente, cada elemento se comporta como una caja que tiene varias partes. Primero está el contenido, que es el texto o imagen. Luego está el padding, que es el espacio entre el contenido y el borde. Después está el border, que es el borde que rodea la caja. Y por último está el margin, que es el espacio que separa esa caja de otros elementos.
